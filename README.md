
# IDEPRO PWA

## Como publicar no GitHub Pages

1. Crie um repositório no GitHub
2. Faça upload de todos os arquivos desta pasta
3. Vá em:
   Settings > Pages
4. Em Source:
   Deploy from branch
5. Selecione:
   main / root
6. Salve

Seu app ficará online.

## IMPORTANTE

Antes de publicar:
- Abra o arquivo index.html
- Procure:
  COLOQUE_SUA_CHAVE_GEMINI_AQUI
- Coloque sua chave Gemini real

## Recursos

- PWA instalável
- Android/iPhone
- Offline básico
- Compartilhamento nativo
